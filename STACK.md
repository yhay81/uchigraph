# Stack

- Runtime: Cloudflare Workers
- HTTP/UI: Hono and Hono JSX
- Tooling: Vite+, TypeScript, Vitest, Oxlint/Oxfmt, Wrangler
- Persistence: D1 for expiring practices, attempts, reports, and aggregate events
- Client: small dependency-free JavaScript for IME-aware input comparison and graphs
- Public origin: <https://uchigraph.yhay81.com>

Better Auth、R2、外部フォント、解析SDK、広告、決済、AI生成、メール、通知は使いません。アカウント所有、ファイル、外部データ、課金が現在の中核jobに不要なためです。
